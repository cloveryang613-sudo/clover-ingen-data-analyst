# Clover InGen Data Analyst Internship Project

## Project Overview

This repository contains an eight-week data analysis project focused on
synthetic physical AI and robot telemetry data.

## Main Deliverables

- Week 2: Exploratory Data Analysis
- Week 3: Statistical Analysis
- Week 4: Segmentation and Clustering
- Week 5: CV-Informed Feature Analysis
- Week 6: Automated Reporting Pipeline
- Week 7: Dashboard Design
- Week 8: Capstone Report and Executive Deck

## Key Findings

- Aido Rover health depends on multiple temporal and frequency features.
- Battery rolling mean ranked first with an importance of 0.0706.
- Fari response length and sentiment accounted for approximately 68% of model
  feature importance.
- The automated pipeline identified 600 high-risk anomaly periods.

## Repository Structure

- `data/`: synthetic datasets
- `notebooks/`: weekly analysis notebooks
- `reports/`: analytical reports and KPI framework
- `dashboard/`: dashboard application and pre-computed inputs
- `capstone/`: final report, presentation, and retrospective
- `weekly/`: weekly Data Analyst logs
